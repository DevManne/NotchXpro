# NotchXpro
**This project is still ongoing and actively being updated.**

A Dynamic Island-style notch widget for the web, built with React.

## Features
- Hover to expand notch with live clock, battery, weather & music controls
- Toggle widgets on/off from the dashboard
- Adjust opacity and glow effect
- Settings saved automatically in browser

## Tech Stack
- React 19
- Tailwind CSS
- Shadcn UI
- React Router

## Run Locally
'''bash
cd frontend
npm install
npm start
'''

Open [http://localhost:3000](http://localhost:3000)
